# KhaiScan – Product Vision

## Vision
KhaiScan is a Telegram-native Meme Coin Trading Intelligence Bot.

It combines multiple free blockchain scanners into one report, then applies a transparent rules engine and AI-powered reasoning to help traders make faster decisions.

## Core Philosophy
- Every metric answers a trading question.
- Never explain obvious metrics (MC, Age, Price, Volume).
- Interpret only metrics that require judgment.
- AI never invents facts.
- Every score must be explainable.
- Free APIs only.
- If data cannot be verified accurately, omit it.

## Target Users
- Meme coin traders
- Alpha groups
- KOLs
- Degens
- On-chain researchers
