# Product Requirements Document

## User Flow
1. User submits a contract address.
2. Detect chain.
3. Collect data from free APIs.
4. Normalize data.
5. Apply rules engine.
6. Generate lore using AI.
7. Score token.
8. Return Telegram report.

## Report Order
1. Token Header
2. Health Overview
3. Basic Information
4. Lore
5. Security
6. Launch Analysis
7. Holder Analysis
8. Developer Analysis
9. Market Activity
10. Smart Money (only if accurate/free)
11. Risk Flags
12. Decision Engine
13. Why This Score?
14. Summary

## Design Rules
- Dense, readable UI.
- Metric -> Value -> Verdict.
- Detailed report first.
- Summary last (collapsible in future).
